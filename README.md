# Nook

Nook is a bilingual Flutter home decor shopping demo built for the Mobile App Development midterm project.

## Features

- Splash screen and three-page onboarding
- Login and sign-up screens with navigation only
- Product grid and product details
- Arabic and English interface with right-to-left Arabic layout
- Light and dark themes
- Screen files organized in `lib/pages/` and reusable widgets in `lib/widgets/`

## Run

1. Run `flutter pub get`.
2. Select an Android emulator or another Flutter device in Android Studio.
3. Run `lib/main.dart`.

The login and product actions are UI demonstrations; this project does not connect to a backend.
